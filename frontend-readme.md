Scientific Calculator: Frontend
Contributor: Poorvi SV  
Role: Frontend Development  
Technologies: HTML, CSS, JavaScript

1. Frontend Overview
The frontend provides a simple, responsive, and user-friendly interface for the scientific calculator.

2. Planned Features
- Basic arithmetic: addition, subtraction, multiplication, and division
- Modulus and exponentiation
- Trigonometric functions and inverse trigonometric functions
- Degree and radian modes
- Natural logarithm, log base 10, and logarithm with a custom base
- Quadratic equation root calculation
- Unit conversions
- Display of calculation results and errors

3. Technologies
- HTML: Calculator structure and buttons
- CSS: Layout, styling, and responsive design
- JavaScript: User interactions and communication with the backend

4. My Contribution
I am responsible for developing the calculator's frontend interface and connecting user interactions with the calculation functionality.
