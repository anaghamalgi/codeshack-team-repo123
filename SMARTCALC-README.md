# SmartCalc Backend

A REST API backend for SmartCalc built with Java 21, Spring Boot, Spring Data JPA and MySQL.

## Features
- Basic arithmetic: `ADD`, `SUBTRACT`, `MULTIPLY`, `DIVIDE`, `MODULUS`, `POWER`
- Angle conversion: `DEG_TO_RAD`, `RAD_TO_DEG`
- Trigonometry: `SIN`, `COS`, `TAN`, `ASIN`, `ACOS`, `ATAN`
- Logarithms: `LN`, `LOG10`, `LOG_BASE`
- Quadratic equation roots: `QUADRATIC`
- Unit conversion: `CONVERT` categories `LENGTH`, `MASS`, `TIME`, `SPEED`, `AREA`, `VOLUME`, `TEMPERATURE`
- Calculation history: list, delete one entry, clear all entries

## Requirements
- JDK 17

- Maven (or use the Maven wrapper generated by your IDE)
- MySQL Server

## Run locally
1. Create a MySQL database named `smartcalc` (or allow the configured connection to create it).
2. Open `src/main/resources/application.properties` and set `spring.datasource.username` and `spring.datasource.password`, or set environment variables `DB_USERNAME`, `DB_PASSWORD`, and optionally `DB_URL`.
3. Run `SmartCalcApplication.java` from IntelliJ, or run `mvn spring-boot:run`.
4. The API starts at `http://localhost:8080`.

Hibernate `ddl-auto=update` creates/updates the history table automatically during development.

## API examples

### Addition
`POST http://localhost:8080/api/calculations`
```json
{"operation":"ADD","a":12,"b":8}
```

### Sine (angle defaults to degrees)
```json
{"operation":"SIN","a":30,"angleUnit":"DEG"}
```

### Logarithm with base
`a` is the argument and `b` is the logarithm base:
```json
{"operation":"LOG_BASE","a":8,"b":2}
```

### Quadratic equation: ax² + bx + c = 0
```json
{"operation":"QUADRATIC","a":1,"b":-3,"c":2}
```

### Unit conversion
Unit names are case-insensitive. Examples: `mm`, `cm`, `m`, `km`, `in`, `ft`, `g`, `kg`, `lb`, `ms`, `s`, `min`, `h`, `m/s`, `km/h`, `m2`, `cm2`, `ml`, `l`, `C`, `F`, `K`.
```json
{"operation":"CONVERT","a":100,"category":"LENGTH","fromUnit":"km","toUnit":"m"}
```

### History
- `GET http://localhost:8080/api/history`
- `DELETE http://localhost:8080/api/history/1`
- `DELETE http://localhost:8080/api/history`

Successful calculation requests are automatically saved to history.

## Notes
- This starter project intentionally does not include user accounts. All history is shared by whoever accesses this backend. Add authentication and per-user history before deploying for multiple users.
- CORS currently allows a frontend at `http://localhost:3000`. Change `@CrossOrigin` if your frontend uses a different origin.
- This is a starter implementation; test edge cases and review the supported unit names before production use.
